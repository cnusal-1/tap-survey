# 두들김 조사 기록

콘크리트 보수재 들뜸을 두들김 음향으로 조사할 때, **타점 좌표와 타격음을 현장에서
잃지 않고 기록**하는 웹앱. 단일 HTML 파일이라 서버가 필요 없다.

**→ https://cnusal-1.github.io/tap-survey/**

휴대폰에서 열면 된다. 카메라·마이크·오프라인 캐시가 https 에서만 동작하므로
깃허브 페이지스가 그대로 조건을 만족한다. Safari 공유 → 홈 화면에 추가를 하면
앱처럼 전체화면으로 열린다.

## 흐름

1. **조사 정보** — 날짜·교량명·부재·위치. 이 넷이 그대로 파일명이 된다
2. **사진과 치수** — 앱 안 카메라에 4:3 사각 테두리가 뜬다. 조사면을 그 안에 채워
   찍으면 테두리가 곧 박스가 된다. 비율이 고정이라 **가로만 넣으면 세로가 계산된다**.
   비스듬히 찍었으면 모서리를 끌어 원근을 보정한다
3. **두들김 조사** — 사진에서 칠 자리를 찍고 부위 구분을 고른 뒤 3초 수집.
   파형이 실시간으로 그려지고, 품질을 통과하면 자동 저장된다
4. **종료 및 저장** — CSV·사진·WAV 를 같은 이름 한 벌로 내려받거나 깃허브에 올린다

## 좌표

조사면 좌하단이 원점, x 는 우측, y 는 위쪽, 단위 mm. 절대 좌표와 상대 좌표(0–1)를
함께 적는다. 사진을 다시 찍어도 상대 좌표는 같은 자리를 가리킨다.

네 점으로 사영변환을 정확히 풀므로 적합 잔차는 0 이고, 남는 것은 손가락 탭
오차뿐이다 — `σ ≈ 8 px × 축척`. 4000 px 사진이면 σ ≈ 6 mm. 사양은 σ ≤ 25 mm 다.

이 값에 **박스를 실제 경계에 맞춘 정도와 렌즈 왜곡은 들어 있지 않다.**

## 수음

현장을 떠난 뒤에는 되돌릴 수 없는 것만 막는다.

- 자동이득제어·잡음억제·에코제거 해제를 요청하고 **실제로 꺼졌는지 확인**해 기록한다
- **정규화하지 않는다.** 16 bit 변환 시 범위를 벗어난 표본 수를 세어 남긴다
- 클리핑(최대진폭 > 0.95), 신호대잡음비 12 dB 미만, 타격 미검출이면 **저장 거부**
- 3초 창을 통째로 남기되 **온셋 위치와 타격 수를 함께** 기록한다

타점당 WAV 281 KB (48 kHz · 3초 · 16 bit).

## 현장에서 잃지 않게

교량 하부는 통신이 안 되는 곳이 많고, 30타 도중 전화가 온다.

- **서비스 워커** — 한 번 연 뒤로는 신호 없이도 열린다. 깃허브 API 는 캐시하지
  않는다. 안 올라간 조사를 올라갔다고 믿는 게 가장 나쁜 실패다
- **자동 저장** — 타점마다 IndexedDB 에 넣는다. 다시 열면 «하던 조사가 남아 있다»
  가 뜨고, 사진·좌표·음향·입력값이 그대로 복원된다

현장에 나가기 전에 한 번 확인하라 — 페이지 열기 → 권한 허용 → 타점 두어 개 →
**비행기모드 켜고 새로고침**. 앱이 열리고 «이어서 하기» 가 뜨면 된다.

## 조사 결과 모으기 — 여러 사람이 조사한다면

**조사자에게 저장소 쓰기 토큰을 나눠 주지 마라.** 토큰 하나로 저장소 전체를 지울 수
있고, 사람이 늘수록 회수도 관리도 안 된다.

담당자가 `collector.gs` 로 **수집 창구**를 한 번 만들고, 그 주소를 `index.html` 위쪽의
`COLLECT_URL` 에 박아 둔다. 그러면 조사자는 **«데이터 보내기» 를 누르기만** 하면 된다.
암구호도 계정도 없다.

**→ 단계별 안내: https://cnusal-1.github.io/tap-survey/collector-guide.html**

암구호를 두지 않은 대신 창구 쪽에 넷을 두었다 — 이름 검사(조사 파일 형식이 아니면 거부),
크기 제한(20 MB), 하루 상한(600 파일), 차단 스위치. 조사자는 이 넷을 느끼지 않는다.
창구는 쓰기만 하므로 주소가 새어도 남의 자료를 가져갈 수 없고, 조사 폴더마다
`_수신기록.csv` 에 누가 언제 무엇을 올렸는지 남는다.

담당자 본인이 올릴 때는 깃허브 직접 업로드를 쓸 수 있다. 저장소 하나에만
`Contents: Read and write` 를 준 세분화 토큰(fine-grained)을 쓰라. 토큰은 그
브라우저의 `localStorage` 에만 있다.

둘 다 파일을 하나씩 나눠 보낸다. 끊겨도 기록은 기기에 남아 있으니 통신이 되는 곳에서
다시 누르면 된다.

## 출력

CSV 는 머리에 `#` 메타 블록(조사 정보, 조사면 치수, σ, 축척, 사진·망치·마이크
정보), 빈 줄, 그다음 표. 엑셀에서 바로 열리도록 UTF-8 BOM + CRLF.

```
no,tap_id,시각,x_mm,y_mm,x_rel,y_rel,sigma_mm,부위구분,비고,
사진_px_u,사진_px_v,음향파일,타격수,최대진폭,SNR_dB,온셋_ms,클리핑
```

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 본체. 외부 자원은 웹폰트뿐 |
| `sw.js` | 서비스 워커. 오프라인 캐시 |
| `collector.gs` | 수집 창구. 담당자가 한 번 만든다 |
| `collector-guide.html` | 수집 창구 만드는 법 — 단계별 안내 |

둘이 같은 폴더에 있어야 오프라인 캐시가 걸린다.
